# Sistema de Gestão de Treinamentos

Este repositório reúne a documentação consolidada do Sistema de Gestão de Treinamentos, organizada para apoiar a apresentação formal da proposta, a validação do escopo e a futura implementação da solução.

## Acesso à documentação

A estrutura principal está disponível em [docs/](docs/).

## Escopo documental

O conjunto documental contempla:

- capa institucional;
- proposta comercial;
- especificação funcional;
- regras de negócio;
- requisitos funcionais;
- requisitos não funcionais;
- modelo de dados;
- fluxos operacionais;
- diagramas e materiais de apoio;
- anexos complementares.

## Direcionamento de leitura

Para melhor compreensão da solução, recomenda-se a leitura na seguinte ordem:

1. Capa e proposta comercial.
2. Especificação funcional.
3. Regras de negócio e requisitos.
4. Modelo de dados e fluxos.
5. Diagramas e anexos.

## Observação

Os artefatos binários oficiais previstos para a pasta de anexos deverão ser incorporados quando disponibilizados pela equipe responsável.
